# PBR 필터 변형 검증 — "금융·지주 쏠림" 지적에 대한 백테스트 (2026-08-04)

배경: 가치투자 탭이 저PBR 종목만 담아 금융·지주 위주로 구성된다는 지적과,
"PBR 2배 이상에 필터를 걸라"는 제안의 유효성 검증.
조건: 2021-07 ~ 2026-07-13, 코스피200+코스닥150 포인트인타임, 월간 리밸런싱,
현행 라이브 설정(fade RIM 안전마진 관문 + 12-1 모멘텀 정렬, F-Score 미사용)과 동일.
실행: `value_backtest.py --sort momentum --no-fscore` + 신규 검증 축 `--pbr-min` / `--exclude-fin`.

## 사실 확인
- 현재 라이브 후보 20종목 중 8종목(40%)이 금융·지주 키워드 — **쏠림 지적은 사실**.
- 백테스트 전 기간 선정 종목의 48%가 금융·지주.

## 결론
1. **"PBR 2 이상 필터"는 유의미한 전략이 아니다.** RIM 기반 안전마진 관문과 구조적으로 양립 불가
   — PBR 2배는 시장이 이미 자본 대비 2배 프리미엄을 준 상태라 fade RIM 적정가 대비 15% 할인이 수학적으로 거의 불가능.
   문자 그대로 적용하면 후보 0개, 상한 완화(≤2.0)로 적용하면 결과가 1도 안 바뀐다 (PBR 필터가 아니라 마진 관문이 지배적).
2. **금융·지주 제외도 개선이 아니라 훼손이다.** 2021~2026 구간에서 금융·지주가 이 전략 수익의 주된 기여자
   (밸류업 프로그램·주주환원 랠리). 제외 시 CAGR 10.6%→4.5%, MDD -30%→-38%.
3. 쏠림 지적 자체는 타당하나, 이는 저PBR 딥밸류 전략의 **정의상 귀결**이지 버그가 아니다.
   고PBR 우량주는 별도 탭(quality_growth)이 이미 담당 — 가치투자 탭에서 해결할 문제가 아님.
4. 실서비스 변경 없음 권고. 원하면 프론트에 섹터 라벨/비중 표시로 쏠림을 "보이게" 하는 것이 올바른 대응.

한계: 금융·지주 판별은 종목명 키워드 휴리스틱(라이브 `_FIN_KEYWORDS`와 동일). 단일 기간(5y)이라
금융주 강세 레짐 의존성 있음 — 다만 "PBR≥2 필터 후보 0개"는 레짐 무관한 구조적 결론.
